# Data source

`raw/ai4i2020.csv` is the AI4I 2020 Predictive Maintenance Dataset.

- **Publisher:** UCI Machine Learning Repository
- **Page:** https://archive.ics.uci.edu/dataset/601
- **DOI:** https://doi.org/10.24432/C5HS5C
- **License:** Creative Commons Attribution 4.0 International (CC BY 4.0)

Citation: AI4I 2020 Predictive Maintenance Dataset [Dataset]. (2020). UCI Machine Learning Repository. https://doi.org/10.24432/C5HS5C

`quality.db` is generated by `python run.py etl` and is not stored in the repository.
